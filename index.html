Three jobs working together

  • HTML: creates the button and message.
  • CSS: styles their appearance.
  • JavaScript: changes the message after a click.

VS Code is the editor where you change these files. Git records versions, and GitHub stores a remote copy for sharing and collaboration.

Audience, need, and genre

The audience is who the experience serves. The need is what they want to understand or accomplish. The genre is the type of experience, such as a tutorial, mystery, or game.

Our earlier group story board used a horror setting and different character roles. This guide uses an instructional genre to help a newcomer learn.

Template, library, and package

  • Template: starting files you adapt.
  • Library: reusable code that solves a problem.
  • Package: a distributable unit of code with a description.

A 3D template can already connect a scene to a library. You change the scene without writing an entire 3D engine.

The workshop package.json

The catalog npm tool

A package supplies reusable code, such as a date formatter or 3D library. You still design the audience’s experience. The parts list identifies dependencies, and the lockfile records exact versions.

Installed copies commonly live in node_modules, which usually stays out of GitHub. This small website uses plain JavaScript and does not need npm.

04 / NETWORK AND PEOPLE

How it reaches others

Browser
Needs a page DNS / name server
Finds its address Site server
Sends resources Browser
Displays the page

DNS helps resolve a domain to an address. The browser requests resources from the site server and uses them to display the page. Cached information can let it skip some requests.

GitHub helps people share and review code. Discord helps classmates explain choices, ask questions, and give feedback.

A configured GitHub Actions workflow can run checks after a push. A maintainer may use a release workflow to publish a package version; a push alone does not update everyone’s copy.
