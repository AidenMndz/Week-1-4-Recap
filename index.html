WEEK 03 / STORYTELLING AND AAA

Give the experience a purpose.

Plan for your audience and build understanding through experience.

The AAA framework

AAA stands for Application, Action, and Amplification. The idea is to start with something usable, understand how it works, and then build beyond the starting point.

Application
Try something usable Action
Learn the concepts and improve it Amplification
Expand and apply the learning elsewhere
  • Application: Start using a working template, prototype, or example before understanding every detail.
  • Action: Learn the concepts, methods, and definitions that help explain and improve what you have already tried.
  • Amplification: Explore deeper ideas, make creative changes, and apply what you learned to new situations.

Website example: Try a working button, learn how its JavaScript handles a click, then use that knowledge to create a different useful interaction.

Based on Attention First · The Human Standard, pages 31–34.

Audience, need, and genre

  • Audience: who the experience serves.
  • Need: what they want to understand or accomplish.
  • Genre: the type of experience, such as a tutorial, mystery, or game.

Our earlier group story board used a horror setting and different character roles. This guide uses an instructional genre to help a newcomer learn.

WEEK 04 / PEEK AND 3D

Give people a reason to explore.

Use curiosity, meaningful interaction, and 3D to support the learning experience.

PEEK: make people want to explore

PEEK stands for Playful Engagement for Entertaining Knowledge. It uses curiosity, challenge, and connection to invite someone into learning.

Curiosity
Give someone a reason to investigate Challenge
Offer a small task with useful feedback Connection
Relate the experience to something meaningful
  • Curiosity: Start with a question, mystery, or unexpected result.
  • Challenge: Give the visitor something manageable to try and show feedback that helps them learn.
  • Connection: Show how the topic relates to the visitor’s interests, values, or goals.

PEEK should lead into meaningful activity. A flashy animation by itself does not explain or teach the topic.

Website example: Ask the visitor to predict what a button will do, let them try it, and then explain how JavaScript produced the result.

Based on Attention First · The Human Standard, pages 49–51.

Our Week 4 recap describes applying storytelling to web development and incorporating 3D elements. The class guide identifies Babylon.js as the library that helped power the scene.

A 3D scene can invite exploration. Giving the visitor a question or task helps connect that exploration to something they can learn.

Template, library, and package

  • Template: starting files you adapt.
  • Library: reusable code that solves a problem.
  • Package: a distributable unit of code with a description.

A 3D template can already connect a scene to a library. You change the scene without writing an entire 3D engine.

The package shelf: a workshop analogy

Your app
The workshop package.json
The parts list npm registry
The catalog npm tool
The delivery Lockfile
The exact receipt

A package supplies reusable code, such as a date formatter or a 3D library. You still design the audience’s experience.

The parts list identifies dependencies, and the lockfile records exact versions. Installed copies commonly live in node_modules, which usually stays out of GitHub.

This guide’s own navigation and feedback use plain JavaScript. They do not need npm installation.

04 / NETWORK AND PEOPLE

How it reaches others

Browser
Needs a page DNS / name server
Finds its address Site server
Sends resources Browser
Displays the page

DNS helps resolve a domain to an address. The browser requests resources from the site server and uses them to display the page. Cached information can let it skip some requests.

GitHub helps people share and review code. Discord helps classmates explain choices, ask questions, and give feedback.

A configured GitHub Actions workflow can run checks after a push. A maintainer may use a release workflow to publish a package version; a push alone does not update everyone’s copy.
